Sama Ashour - Rapunzel Portfolio (editable project)

index.html      -> page structure (sections, music control)
css/style.css   -> all colors (see :root variables), fonts, animations, layout
js/config.js    -> YOUR INFO: photo, GitHub, LinkedIn, email, phone, projects, certificates
js/content.js   -> fills the page from config.js
js/scene.js     -> castle/mountains/trees artwork, parallax, stars, lanterns, sparkles
js/audio.js     -> synthesized music (chords/melody) and sound effects
js/main.js      -> cinematic intro timeline, Skip/Enter buttons, scroll reveal

How to run: open index.html in a browser (online for Google Fonts).
Deploy: upload the whole folder to GitHub Pages / Netlify / Vercel.
Keep the script order in index.html as it is.
